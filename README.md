
Tradutor V1

Este é um programa simples feito em Python que traduz a frase:

"swim, swim, swim, water falling of your skin"

Funcionalidades
- Tradução para português 🇧🇷
- Tradução para espanhol 🇪🇸
- Tradução para francês 🇫🇷
- Loop até o usuário sair

Linguagem 
- Python

Conceitos 
- print()
- input()
- variáveis
- if / else
- while (loop)
